## 🚀 Kurulum

1. `woocommerce-otomatik-lisans-teslimat-berat-k.zip` dosyasını indirin
2. WordPress Admin Panel → Eklentiler → Yeni Ekle → Eklenti Yükle
3. ZIP dosyasını seçin ve yükleyin
4. Eklentiyi etkinleştirin
5. Lisans anahtarı: `BERAT-K-DEVELOPER-LICENSE-KEY`

## 🛠️ Kullanım

1. **Ürün Ayarlama**:
   - WooCommerce → Ürünler → Ürünü Düzenle
   - "Lisans Anahtarları" alanını bulun
   - Her satıra bir lisans anahtarı ekleyin

2. **Admin Paneli**:
   - WordPress Admin → Lisans Anahtarları
   - Gerçek zamanlı istatistikleri görün
   - Lisans anahtarlarını toplu olarak yönetin

3. **Müşteri Deneyimi**:
   - Otomatik e-posta teslimatı
   - Hesabımda "Lisans Anahtarlarım" bölümü
   - Sipariş detaylarında lisans anahtarları
